# Abhinav Vashishth — Portfolio

A single-page portfolio for my backend engineering work, projects, certifications, LinkedIn activity, and photography.

## Explore

- **Experience:** Java and Spring Boot backend development, API optimization, and enterprise systems.
- **Projects:** QuickDevBase, an IoT platform, and an AI news automation prototype.
- **Certifications:** IBM Java Developer Professional Certificate and Apache Kafka Essential Training, with downloadable PDFs in [`certificates/`](certificates/).
- **Activity:** LinkedIn posts, articles, and images.
- **Beyond Code:** Travel films and photography from Himachal.

## Run locally

Open [`index.html`](index.html) in a browser. No build step or package installation is needed. The page uses CDN-hosted Tailwind CSS, GSAP, Three.js, Font Awesome, and Google Fonts, so an internet connection is needed for the full design and animations.

## Update the content

The site is maintained in [`index.html`](index.html):

- Edit the section markup to update experience, projects, and certifications.
- Edit the `linkedInPosts` array near the bottom of the file to update the Activity carousel.
- Keep certificate links relative to this repository and place their PDF files in [`certificates/`](certificates/).

The portfolio is responsive: phones use a menu button, while larger screens use the dock navigation.
